# Google L4 Interview Questions (Graphs, System Design)

## Questions

### Graphs · Medium
Given a dataset of movies with ratings and a similarity graph, design an algorithm to find and return the top K most similar movies to a given movie, ranked by their rating. The follow-up was to optimize for O(N * log K) time and O(K) space.

**Approach:** Traverse the graph (using BFS or DFS) from the starting movie to find similar movies. Maintain a min-heap of size K to keep track of the top K movies seen so far based on their rating.

### System Design · Hard
Design an `AdServer` with `insertAd(content, score)` and `getAd()` methods. `getAd()` must return the ad with the highest score, then decrease its score. A crucial constraint is that the same ad cannot be returned on two consecutive calls. A follow-up added a cooldown period before an ad can be re-served.

**Approach:** Use a max-heap to quickly access the ad with the highest score. To handle the "no consecutive" rule, when an ad is served, pop it, and temporarily store it. Pop the next-best ad, serve it, and then push the first ad back into the heap. The cooldown requires a more complex design, possibly using a hash map to track ad cooldown timers along with the heap.

### Graphs · Medium
Given a 2D grid of land and water, find all 'lakes' (bodies of water completely surrounded by land and not touching the border). A follow-up asked how to handle islands of land inside a lake.

**Approach:** Use a graph traversal algorithm like BFS or DFS. First, iterate through the grid's border cells. Any water cell connected to the border is not a lake, so run a traversal (e.g., flood-fill) from each border water cell to mark all connected water cells as "not a lake". In a second pass, any remaining, unvisited water cell must be part of a lake.
