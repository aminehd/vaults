# Google L4 Interview (Topo Sort, LFU Cache variant)

**2026-05-19** · [LeetCode](https://leetcode.com/discuss/post/8265899/google-l4-interview-reject-by-anonymous_-xsc3/)

## Questions

### Graph Theory · Medium
Given a set of courses and a list of prerequisite pairs, determine if it is possible to finish all courses. If so, return a valid order in which they can be taken.

**Approach:** This is a classic application of topological sorting. Use Kahn's algorithm (with a queue and in-degrees) or DFS-based topological sort to detect cycles and find a valid course order.

### Data Structure Design · Hard
Design a cache similar to LFU, but with a custom eviction policy. When capacity is reached, evict from the group of least frequently used items, but only items whose `score` is an even number. If there's a tie, evict the least recently used among them.

**Approach:** This requires combining elements of LFU and LRU caches. Use a hash map for key-value lookups. Use another hash map to group keys by their access frequency. Within each frequency group, maintain a doubly-linked list to track the recency of use, allowing for O(1) eviction of the LRU item that meets the even score criteria.
