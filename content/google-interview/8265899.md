# Google L4 Interview Questions (Course Schedule, LFU Cache)

**2026-05-19T05:00:36.162136** · [LeetCode](https://leetcode.com/discuss/post/8265899/google-l4-interview-reject-by-anonymous_-xsc3/)

## Questions

### Graph · Medium
Given a set of courses and a list of prerequisite pairs, determine if it is possible to finish all courses. If it is, return one valid order in which the courses can be taken.

**Approach:** This is a classic topological sort problem. Build a directed graph from the prerequisites. Use Kahn's algorithm (with a queue and in-degrees) or DFS to detect cycles and find a valid ordering.

### Data Structure Design · Hard
Design a cache similar to LFU (Least Frequently Used), but with a custom eviction policy. The cache stores `(key, {content, score})` pairs. When evicting, you must choose from the least frequently used items, but only those whose `score` is an even number. If there's a tie, evict the least recently used among them.

**Approach:** This requires a complex data structure. A common LFU implementation uses a hash map for key-to-node lookups and a doubly linked list for each frequency count. This variation adds a condition on the `score`, so the eviction logic within the lowest-frequency list would need to be modified to scan for items with an even score.
