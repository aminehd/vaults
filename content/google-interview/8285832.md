# Shortest Path with Time Windows using Dijkstra

**2026-05-24** · [LeetCode](https://leetcode.com/discuss/post/8285832/shortest-path-with-time-windows-dijkstra-ejcv/)

## Questions

### Graph · Medium
You are given a directed weighted graph of `n` nodes (0-indexed) and a list of edges where `edges[i] = [u, v, w, open, close]`. This represents a directed edge from `u` to `v` with travel cost `w`. The edge is only traversable at a specific time `t` if `open <= t < close`. Find the **minimum cost** to travel from node `0` to node `n-1`.

**Example:**
```
Input: n=4, edges=[[0,1,2,0,5],[0,2,5,0,3],[1,3,3,2,10],[2,3,1,4,8]]
Output: 5
Explanation: 
- Go from 0 to 2 at time 0 (cost 5). Arrive at time 5.
- Wait until time 4.
- Go from 2 to 3 at time 4 (cost 1). Arrive at time 5.
Total cost is 5.
```

**Approach:** This problem can be solved using a modification of Dijkstra's algorithm. The state in the priority queue needs to be `(cost, node, time)` to handle the time window constraints. The complexity is O(E log V) where E is the number of edges and V is the number of vertices.
