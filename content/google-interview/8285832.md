# Shortest Path with Time Windows (Dijkstra)

**2026-05-24** · [LeetCode](https://leetcode.com/discuss/post/8285832/shortest-path-with-time-windows-dijkstra-ejcv/)

## Questions

### Graph · Medium
You are given a directed weighted graph of `n` nodes (0-indexed) and a list of edges where `edges[i] = [u, v, w, open, close]`. This represents a directed edge from `u` to `v` with travel cost `w`. The edge is only traversable at a specific time `t` if `open <= t <= close`. Find the minimum cost to travel from node `0` to node `n-1`.

**Example:**
```
Input: n=4, edges=[[0,1,2,0,5],[0,2,5,0,3],[1,3,3,2,10],[2,3,1,4,8]]
Output: 5
Explanation:
Path 0->1->3: Arrive at 1 at time 2 (cost 2). Wait until t=2 to take edge. Arrive at 3 at time 2+3=5. Total cost 5.
Path 0->2->3: Arrive at 2 at time 5 (cost 5). But edge [2,3] is only open at t=4. So this path is invalid.
```

**Approach:** Use Dijkstra's algorithm with a 3D state in the priority queue: `{cost, node, time}`. This is because the path depends not just on the cost to reach a node, but also the arrival time, which affects which future edges are open.
