# Shortest Path with Time Windows — Dijkstra + 3D State

**2026-05-24** · [LeetCode](https://leetcode.com/discuss/post/8285832/shortest-path-with-time-windows-dijkstra-ejcv/)

## Problem · Algorithms · Medium

You are given a directed weighted graph of `n` nodes (0-indexed) and a list of edges:

`edges[i] = [u, v, w, open, close]`

Directed edge from `u` to `v` with travel cost `w`, only traversable when current time `t` satisfies `open ≤ t < close`.

Find the **minimum cost** to travel from node `0` to node `n-1`.

**Test cases:**
```
n=4, edges=[[0,1,2,0,5],[0,2,5,0,3],[1,3,3,2,10],[2,3,1,4,8]] → 5
n=3, edges=[[0,1,4,0,2],[1,2,3,5,9]] → 7
n=3, edges=[[0,1,5,0,10],[1,2,3,0,4]] → -1
n=1, edges=[] → 0
```

**Approach:** Dijkstra with 3D state `(cost, node, time)` — track time to know which edges are open at each step.
