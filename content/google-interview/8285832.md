# Shortest Path with Time Windows

**2026-05-24T05:00:21.448672** · [LeetCode](https://leetcode.com/discuss/post/8285832/shortest-path-with-time-windows-dijkstra-ejcv/)

## Questions

### algorithms · medium
You are given a directed weighted graph of `n` nodes (0-indexed) and a list of edges where:

`edges[i] = [u, v, w, open, close]`

This represents a directed edge from `u` to `v` with travel cost `w`.

**Approach:** This problem can be solved using a modification of Dijkstra's algorithm. The state in the priority queue needs to be expanded to include not just the cost and node, but also the current time, to handle the time window constraints on the edges. The complexity will be similar to Dijkstra, likely O(E log V).
