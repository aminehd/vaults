# Shortest Path with Time-Restricted Edges

**2026-05-24T05:00:21.448672** · [LeetCode](https://leetcode.com/discuss/post/8285832/shortest-path-with-time-windows-dijkstra-ejcv/)

## Questions

### Graph · Hard
You are given a directed weighted graph of `n` nodes (0-indexed). Edges are defined as `[u, v, w, open, close]`, representing a directed edge from `u` to `v` with travel cost `w`. Each edge is only usable if your arrival time at node `u` is within the window `[open, close)`. Find the minimum cost to travel from node `0` to `n-1`. If it is impossible, return `-1`. You may wait at any node for free, which increments time by 1 per step.

**Example:**
Input: `n = 4, edges = [[0,1,2,0,5],[0,2,5,0,3],[1,3,3,2,10],[2,3,1,4,8]]`
Output: `5`
Explanation: The path `0 -> 1 -> 3` has a total cost of 5. Arriving at node 1 at t=2 is valid for the edge `1->3` which is open during `[2,10)`.

**Approach:** This problem requires a modification of Dijkstra's algorithm. The state in the priority queue must include not just cost and node, but also the current time, i.e., `(cost, node, time)`. A `visited` array should also be 2D, `visited[node][time]`, to avoid cycles and redundant computations.
