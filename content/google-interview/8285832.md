# Shortest Path with Time Windows using Dijkstra

**2026-05-24T05:00:21.448672** · [LeetCode](https://leetcode.com/discuss/post/8285832/shortest-path-with-time-windows-dijkstra-ejcv/)

## Questions

### algorithms · medium
You are given a directed weighted graph of `n` nodes (0-indexed) and a list of edges where:

`edges[i] = [u, v, w, open, close]`

This represents a directed edge from `u` to `v` with travel cost `w`.

**Example:**
```
Input: n=4, edges=[[0,1,2,0,5],[0,2,5,0,3],[1,3,3,2,10],[2,3,1,4,8]]
Output: 5
Explanation: The path 0 -> 2 -> 3 has a total cost of 5 + 1 = 6, but the edge from 2 to 3 can only be used at time 4, so we arrive at node 3 at time 5. The path 0 -> 1 -> 3 has a total cost of 2 + 3 = 5.
```

**Approach:** This problem can be solved using a modification of Dijkstra's algorithm. The state in the priority queue needs to be augmented to include the current time, in addition to the cost and node.
