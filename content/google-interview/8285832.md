# Shortest Path with Time Windows

**2026-05-24** · [LeetCode](https://leetcode.com/discuss/post/8285832/shortest-path-with-time-windows-dijkstra-ejcv/)

## Questions

### Graph · Hard
You are given a directed weighted graph of `n` nodes (0-indexed) and a list of edges where `edges[i] = [u, v, w, open, close]`. This represents a directed edge from `u` to `v` with travel cost `w`. However, each edge is only usable if your arrival time at node `u` falls within the window `[open, close)`. Find the minimum cost to travel from node `0` to node `n-1`. If it is impossible, return `-1`. You may wait at a node for free.

**Example:**
Input: n = 4, edges = [[0,1,2,0,5],[0,2,5,0,3],[1,3,3,2,10],[2,3,1,4,8]]
Output: 5
Explanation: Path 0 -> 1 -> 3: Arrive at node 1 at t=2. Edge to node 3 is open [2,10). Total cost = 2+3=5.

**Approach:** This problem requires a modification of Dijkstra's algorithm. The state in the priority queue must be expanded from `(cost, node)` to `(cost, node, time)` because the ability to traverse an edge depends on the arrival time, not just the cost to reach the node.
