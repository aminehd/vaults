# Shortest Path with Time Windows — Dijkstra + 3D State

**2026-05-24** · [LeetCode](https://leetcode.com/discuss/post/8285832/shortest-path-with-time-windows-dijkstra-ejcv/)

## Questions

### Algorithms · Medium
You are given a directed weighted graph of `n` nodes and edges of the form `[u, v, w, open, close]` — a directed edge from `u` to `v` with cost `w`, only traversable when current time `t` satisfies `open ≤ t < close`. Find the **minimum cost** from node `0` to node `n-1`.

**Example:**
```
Input:  n=4, edges=[[0,1,2,0,5],[0,2,5,0,3],[1,3,3,2,10],[2,3,1,4,8]]
Output: 5
Explanation: 0→1 (cost 2, t=0→1), wait, 1→3 (cost 3, t=2→3). Total cost = 5.

Input:  n=3, edges=[[0,1,5,0,10],[1,2,3,0,4]]
Output: -1   (can't reach n-1 within any open window)
```

**Approach:** Dijkstra with 3D state `(cost, node, time)`. At each step, only enqueue neighbors whose edge is open at the current time `t`. Track visited `(node, time)` pairs to avoid cycles. O(E log E) time where E = number of edges.
