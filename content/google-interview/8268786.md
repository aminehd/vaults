# Google L3 Interview (Graphs, API-based Search)

**2026-05-19** · [LeetCode](https://leetcode.com/discuss/post/8268786/google-l3-bangalore-india-interview-expe-dt1h/)

An interview experience for a Google L3 role in Bangalore, detailing four rounds of technical questions.

## Questions

### Algorithms & Data Structures · Medium
Given a list of flights (source, destination, departure time, arrival time), find a valid itinerary from a start to a destination airport.

**Approach:** Model the airports and flights as a directed, time-dependent graph. Use a search algorithm like BFS or DFS to explore possible paths. The state in the search queue/stack needs to include the current airport and the current time to validate the next flight's feasibility.

### Problem Solving & Optimization · Hard
An `n x n` grid contains `n-1` non-attacking rooks, leaving one empty row and column. Find the location of the empty row and column by calling `int countRooks(r1, c1, r2, c2)` as few times as possible.

**Approach:** The key is to use binary search to find the empty row and column. To find the empty row, you can query `countRooks(0, 0, mid, n-1)`. If the number of rooks equals `mid+1`, the empty row is in the bottom half; otherwise, it is in the top half. This finds the row in O(log n) calls. Repeat for the column.
