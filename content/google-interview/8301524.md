### Algorithms · Medium — Greedy + Intervals

Solve a problem involving a set of intervals using a greedy approach — merging overlapping intervals, finding the maximum number of non-overlapping intervals, or scheduling.

**Example:**
Input: intervals = [[1,3],[2,6],[8,10],[15,18]]
Output: [[1,6],[8,10],[15,18]]

**Approach:** Sort intervals by start time, then greedily merge by comparing each interval's start with the previous end. O(n log n) time, O(n) space.

### Algorithms · Medium — Topological Sort

Given a set of dependencies or a DAG, implement a topological sort to find a linear ordering of its vertices.

**Example:**
Input: numCourses = 4, prerequisites = [[1,0],[2,0],[3,1],[3,2]]
Output: [0,1,2,3] or [0,2,1,3]

**Approach:** Kahn's algorithm (BFS with in-degree tracking) or DFS with a visited/stack. Detect cycles by checking if all nodes are processed. O(V+E) time.

### Algorithms · Medium — Dijkstra's Shortest Path

Given a weighted graph, implement Dijkstra's algorithm to find the shortest path from a source node to all other nodes.

**Example:**
Input: graph = {0: [(1,4),(2,1)], 1: [(3,1)], 2: [(1,2),(3,5)], 3: []}, src = 0
Output: {0:0, 1:3, 2:1, 3:4}

**Approach:** Min-heap (priority queue) storing (dist, node). Relax neighbors greedily. Skip stale entries. O((V+E) log V) time.

### Implementation / System Design · Medium — LRU / LFU Cache

Design and implement a cache with fixed capacity supporting `get` and `put` with LRU or LFU eviction. Interviewer noted missing some edge cases.

**Example (LRU):**
Input: capacity=2, ops=[put(1,1), put(2,2), get(1), put(3,3), get(2)]
Output: get(1)=1, get(2)=-1 (evicted)

**Approach:** LRU — doubly linked list + hashmap for O(1) get/put. LFU — two hashmaps (key→val/freq, freq→OrderedDict) + min_freq tracker. O(1) both operations.
