# Google Application Engineer — Coding Round Questions

**2026-05-24** · [LeetCode](https://leetcode.com/discuss/post/8286412/google-application-engineer-upcoming-cod-99aa/)

## Questions

### String Manipulation · Easy
Given two strings `s1` and `s2`, determine if `s2` is a permutation (anagram) of `s1`.

### Matrix Manipulation · Medium
Given an `n × n` 2D matrix representing an image, rotate it 90° clockwise **in-place** — do not allocate another matrix.

### Combinatorics · Medium
Given an integer array `nums` of unique elements, return all possible subsets (the power set). No duplicate subsets.

### String Manipulation · Medium
Given a smaller string `s` and a bigger string `b`, find all permutations of `s` within `b` and return the starting indices.

### Array Manipulation · Easy
Given two integer arrays `A` and `B`, both sorted in non-decreasing order, merge `B` into `A` in-place such that `A` remains sorted. `A` has enough buffer at the end.
