# Google Application Engineer Coding Questions

**2026-05-24** · [LeetCode](https://leetcode.com/discuss/post/8286412/google-application-engineer-upcoming-cod-99aa/)

## Questions

### String Manipulation · Easy
Given two strings, `s1` and `s2`, write a function to determine if `s2` is a permutation (anagram) of `s1`.

**Example:**
```
Input: s1 = "anagram", s2 = "nagaram"
Output: true
```

**Approach:** Use a hash map (or an array of size 26 for lowercase letters) to count character frequencies in `s1`, then decrement for `s2`. If all counts are zero, it's an anagram. O(n) time, O(1) space.

### Matrix Manipulation · Medium
You are given an `n x n` 2D matrix representing an image. Write a function to rotate the image by 90 degrees (clockwise). You must do this in-place.

**Example:**
```
Input: matrix = [[1,2,3],[4,5,6],[7,8,9]]
Output: [[7,4,1],[8,5,2],[9,6,3]]
```

**Approach:** First, transpose the matrix (swap `matrix[i][j]` with `matrix[j][i]`). Then, reverse each row. O(n^2) time, O(1) space.

### Combinatorics · Medium
Given an integer array `nums` of unique elements, return all possible subsets (the power set). The solution set must not contain duplicate subsets.

**Example:**
```
Input: nums = [1,2,3]
Output: [[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

**Approach:** Use backtracking. For each element, explore two choices: include it in the current subset or not. This recursively builds all combinations. O(2^n) time.

### String Manipulation · Medium
Given a smaller string `s` and a bigger string `b`, design an algorithm to find all permutations of the shorter string within the longer one. Print the location of each permutation.

**Example:**
```
Input: s = "abbc", b = "cbabadcbbabbc"
Output: 0, 6, 9, 10
```

**Approach:** Use a sliding window and two hash maps to track character frequencies of `s` and the current window in `b`. O(len(b)) time.

### Array Manipulation · Easy
You are given two integer arrays, `A` and `B`, sorted in non-decreasing order. Array `A` has a large enough buffer at the end to hold `B`. Merge `B` into `A` in-place, sorted.

**Example:**
```
Input: A = [1,2,3,0,0,0], m = 3, B = [2,5,6], n = 3
Output: A = [1,2,2,3,5,6]
```

**Approach:** Use two pointers starting from the end of `A` (the meaningful part) and `B`. Compare elements and place the larger one at the end of `A`, moving backward. O(m+n) time.
