# Google Application Engineer Interview Questions

**2026-05-24T05:00:21.413013** · [LeetCode](https://leetcode.com/discuss/post/8286412/google-application-engineer-upcoming-cod-99aa/)

This post lists several questions a candidate received in a prep document for a Google Application Engineer role, covering common topics like string/array manipulation, matrix rotation, and combinatorics.

## Questions

### String Manipulation · Easy
Given two strings, `s1` and `s2`, write a function to determine if `s2` is a permutation (anagram) of `s1`.

**Approach:** Use a frequency map (e.g., a hash map or an integer array of size 26) to count characters in `s1`, then decrement counts for characters in `s2`. If all counts are zero at the end, it's a permutation.

### Matrix Manipulation · Medium
You are given an `n x n` 2D matrix representing an image. Write a function to rotate the image by 90 degrees (clockwise) in-place.

**Approach:** The standard approach is to first transpose the matrix (swap `matrix[i][j]` with `matrix[j][i]`) and then reverse each row.

### Combinatorics · Medium
Given an integer array `nums` of unique elements, return all possible subsets (the power set). The solution set must not contain duplicate subsets.

**Approach:** Use backtracking or recursion. For each element, there are two choices: either include it in the current subset or not.

### String Manipulation · Medium
Given a smaller string `s` and a bigger string `b`, design an algorithm to find all permutations of the shorter string within the longer one. Print the location of each permutation.

**Approach:** This is a classic sliding window problem. Maintain a frequency map for the pattern string `s`. Slide a window of `len(s)` across the bigger string `b`, updating a frequency map for the current window and comparing it to the pattern's map at each step.

### Array Manipulation · Easy
You are given two integer arrays, `A` and `B`, sorted in non-decreasing order. Array `A` has a large enough buffer at the end to hold all elements of `B`. Write a function to merge `B` into `A` in-place, such that the resulting array `A` is sorted.

**Approach:** Use a two-pointer approach starting from the end of both arrays. Compare the elements and place the larger one at the end of array `A`, moving backward.
