# Google Application Engineer Interview Questions

**2026-05-24** · [LeetCode](https://leetcode.com/discuss/post/8286412/google-application-engineer-upcoming-cod-99aa/)

## Questions

### String Manipulation · Easy
Given two strings, `s1` and `s2`, write a function to determine if `s2` is a permutation (anagram) of `s1`.

**Example:**
```
Input: s1 = "listen", s2 = "silent"
Output: true
```

**Approach:** Use a hash map to count character frequencies in s1, then decrement for s2. O(n) time, O(1) space (alphabet size).

### Matrix Manipulation · Medium
You are given an `n x n` 2D matrix representing an image. Write a function to rotate the image by 90 degrees (clockwise). You must rotate the image in-place.

**Example:**
```
Input:
[
  [1,2,3],
  [4,5,6],
  [7,8,9]
]
Output:
[
  [7,4,1],
  [8,5,2],
  [9,6,3]
]
```

**Approach:** Transpose the matrix, then reverse each row. O(n^2) time, O(1) space.

### Combinatorics · Medium
Given an integer array `nums` of unique elements, return all possible subsets (the power set). The solution set must not contain duplicate subsets.

**Example:**
```
Input: nums = [1,2,3]
Output: [[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

**Approach:** Use backtracking/recursion to build subsets, exploring both including and not including each element. O(2^n * n) time.

### String Manipulation · Medium
Given a smaller string `s` and a bigger string `b`, design an algorithm to find all permutations of the shorter string within the longer one. Print the location of each permutation.

**Example:**
```
Input: s = "abbc", b = "cbabadcbbabbc"
Output: 0, 6, 9, 10
```

**Approach:** Use a sliding window and two frequency maps to compare the window in `b` with `s`. O(len(b)) time.

### Array Manipulation · Easy
You are given two integer arrays, `A` and `B`, sorted in non-decreasing order. Array `A` has a large enough buffer at the end to hold all elements of `B`. Write a function to merge `B` into `A` in-place, such that the resulting array `A` is sorted.

**Example:**
```
Input: A = [1,2,3,0,0,0], m = 3, B = [2,5,6], n = 3
Output: [1,2,2,3,5,6]
```

**Approach:** Use two pointers starting from the end of `A` and `B` to fill `A` from the back. O(m+n) time.
