## Questions

### String Manipulation · Easy
Given two strings `s1` and `s2`, determine if `s2` is a permutation (anagram) of `s1`.

**Example:**
```
Input:  s1 = "abc", s2 = "cab"
Output: true

Input:  s1 = "abc", s2 = "car"
Output: false
```

**Approach:** Count character frequencies with a hash map (or array of 26). Compare counts — O(n) time, O(1) space.

### Matrix Manipulation · Medium
Given an `n × n` matrix, rotate it 90° clockwise **in-place**.

**Example:**
```
Input:             Output:
1 2 3              7 4 1
4 5 6    →         8 5 2
7 8 9              9 6 3
```

**Approach:** Transpose (swap `matrix[i][j]` and `matrix[j][i]`), then reverse each row. O(n²) time, O(1) space.

---

### Combinatorics · Medium
Given an integer array `nums` of unique elements, return all possible subsets (power set).

**Example:**
```
Input:  nums = [1, 2, 3]
Output: [[], [1], [2], [3], [1,2], [1,3], [2,3], [1,2,3]]
```

**Approach:** Backtracking — at each index, choose to include or exclude the element. 2ⁿ subsets total, O(n·2ⁿ) time.

### String Manipulation · Medium
Given a smaller string `s` and a bigger string `b`, find all starting indices where a permutation of `s` appears in `b`.

**Example:**
```
Input:  s = "ab", b = "eidbaooo"
Output: [1, 3]   (b[1..2]="id"? No — b[3..4]="ba" ✓, b[1..2]="ei"? No)

Input:  s = "ab", b = "abab"
Output: [0, 1, 2]
```

**Approach:** Sliding window of size `len(s)` over `b`, maintain frequency counts of current window. Compare with `s` counts — O(n) time.

### Array Manipulation · Easy
Given two sorted arrays `A` (with extra buffer) and `B`, merge `B` into `A` in-place so `A` remains sorted.

**Example:**
```
Input:  A = [1, 3, 5, 0, 0, 0], B = [2, 4, 6]
Output: A = [1, 2, 3, 4, 5, 6]
```

**Approach:** Two pointers from the end of each array, fill `A` from the back. O(m+n) time, O(1) space.
