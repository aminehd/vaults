### String Manipulation · easy
Given two strings, `s1` and `s2`, write a function to determine if `s2` is a permutation (anagram) of `s1`.

**Approach:** The simplest approach is to sort both strings and check if they are equal. A more efficient approach is to use a hash map (or a fixed-size array) to count character frequencies in `s1` and then decrement the counts for characters in `s2`.

### Matrix Manipulation · medium
You are given an `n x n` 2D matrix representing an image. Write a function to rotate the image by 90 degrees (clockwise). You must rotate the image in-place.

**Approach:** This can be done in two steps: first, transpose the matrix (swap `matrix[i][j]` with `matrix[j][i]`), and then reverse each row.

### String Manipulation · medium
Given a smaller string `s` and a bigger string `b`, design an algorithm to find all permutations of the shorter string within the longer one. Print the location of each permutation.

**Approach:** This can be solved efficiently using a sliding window and two hash maps (or arrays) to keep track of character frequencies of the pattern string and the current window in the larger string.

### Array Manipulation · easy
You are given two integer arrays, `A` and `B`, sorted in non-decreasing order. Array `A` has a large enough buffer at the end to hold all elements of `B`. Write a function to merge `B` into `A` in-place.

**Approach:** Use a two-pointer approach, starting from the end of both arrays. Compare the elements and place the larger one at the end of array `A`.
