# Google Application Engineer Coding Questions

## Questions

### String Manipulation · easy
Given two strings, `s1` and `s2`, write a function to determine if `s2` is a permutation (anagram) of `s1`.

**Example:**
```
Input: s1 = "listen", s2 = "silent"
Output: true
```

**Approach:** This can be solved by sorting both strings and comparing them, or by using a hash map to count character frequencies. The hash map approach is O(n) time and O(1) space (assuming a fixed character set).

### Matrix Manipulation · medium
You are given an `n x n` 2D matrix representing an image. Write a function to rotate the image by 90 degrees (clockwise).

**Constraint:** You must rotate the image in-place, which means you have to modify the input 2D matrix directly. Do not allocate another 2D matrix for the rotation.

**Example:**
```
Input:
[
  [1,2,3],
  [4,5,6],
  [7,8,9]
]
Output:
[
  [7,4,1],
  [8,5,2],
  [9,6,3]
]
```

**Approach:** A common in-place approach is to first transpose the matrix and then reverse each row. This results in a 90-degree clockwise rotation.

### Combinatorics · medium
Given an integer array `nums` of unique elements, return all possible subsets (the power set).

The solution set must not contain duplicate subsets.

**Example:**
```
Input: nums = [1,2,3]
Output: [[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

**Approach:** This can be solved using backtracking or recursion. For each element, we have two choices: either include it in the current subset or not.

### String Manipulation · medium
Implement a solution for: Given a smaller string s and a bigger string b, design an algorithm to find all permutations of the shorter string within the longer one. Print the location of each permutation.

**Example:**
```
Input: s = "abc", b = "abcbac"
Output:
Found at index 1: "bca"
Found at index 2: "cab"
Found at index 3: "bac"
```

**Approach:** This can be solved using a sliding window and two hash maps to keep track of character frequencies of the shorter string and the current window in the longer string.

### Array Manipulation · easy
You are given two integer arrays, `A` and `B`, sorted in non-decreasing order. Array `A` has a large enough buffer at the end to hold all elements of `B`.

Write a function to merge `B` into `A` in-place, such that the resulting array `A` is sorted.

**Example:**
```
Input: A = [1,2,3,0,0,0], B = [2,5,6]
Output: [1,2,2,3,5,6]
```

**Approach:** This can be solved using a two-pointer approach, starting from the end of both arrays and filling the merged array from the end of array A.
